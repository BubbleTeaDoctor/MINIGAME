# DynamicPortrait v12

这版按你的最新要求升级为 **10 个职业**，并把职业特效的视觉差异拉大：

## 职业列表
- mage（法师）
- priest（牧师）
- hunter（猎人）
- monk（武僧）
- assassin（刺客）
- samurai（武士）
- warrior（战士）
- shaman（萨满）
- necromancer（死灵法师）
- warlock（术士）

## 特效差异（更明显）
- **法师**：大号符文、法球、旋转奥术环
- **牧师**：十字圣光、垂直光柱、羽光
- **猎人**：风线、金叶、自然种子微光
- **武僧**：气环扩散、佛珠光点、气流扫动
- **刺客**：影雾、冷色碎片、斩痕闪过
- **武士**：樱花花瓣、刀光斩线、日轮脉冲
- **战士**：火星、尘土、爆燃光斑
- **萨满**：闪电、图腾脉冲、灵体光点
- **死灵法师**：魂火、灰烬、骷髅印记
- **术士**：邪火、暗纹符印、烟雾旋涡

## 仍然保留
- 左胸 / 右胸 / 眼睛的手动框选
- 胸部呼吸参数
- 眨眼与闭眼时长
- 不做头发 / 衣摆形变
